# Sieve: 3-minute demo video

The video is generated by `scripts/video/make_video.py`: an AI voiceover (Microsoft neural voice "Andrew") over a scripted recording of the real site. The narration below is what it says. Numbers are read from `results.json` at build time, so they always match the benchmark; the figures shown here are from the current run.

| # | Screen | Voiceover |
|---|---|---|
| 1 | Title: the Sieve wordmark, the red dot drops onto the line, team names | This is Sieve, a team project by Abbas Rahman, Humayun Arshad and Sunaina Babar. It catches the bad chunks before your LLM reads them. |
| 2 | Slide: the five retrieval threats | Retrieval augmented generation trusts every chunk the retriever returns. Most RAG stacks only check metadata, like the access tags copied into the index. They never read what a chunk actually says. So a hidden instruction, a fake policy, a stale permission, or a leaked key goes straight into the model. |
| 3 | Site hero: chunks raining onto the sieve | Sieve sits between the retriever and the LLM. Every chunk leaves with a decision: allow, redact, or block. And a reason. |
| 4 | Playground, "Poisoned tip: disable MFA" | Here is a real retrieval. Maya asks whether she should disable MFA during deployments. Without Sieve, a metadata filter lets everything through, including a low-trust community tip telling engineers to turn MFA off and route traffic through an unauthenticated proxy. With Sieve, that tip is blocked, and the official MFA policy still reaches the model. |
| 5 | Playground, the two injection scenarios | This uploaded report hides an instruction to bypass safety and print the admin API token. Sieve blocks it. A support ticket with a fake status banner is caught too. |
| 6 | Playground, "Contractor record with PII" | A contractor record leaks a social security number, a personal email, an access token and a home address. Sieve redacts each one, and keeps the rest of the record useful. |
| 7 | Playground, "Account deactivated yesterday" | Alice left the company yesterday. The index still says she is in finance, so the retriever happily returns the Q3 review. Sieve re-checks the live identity provider, sees the account is deactivated, and blocks it. |

| 10 | The independent-cases line is highlighted | We also had a teammate write 45 cases without ever seeing the firewall. On rules alone, 60 percent of those attacks got through. With Nemotron, 5.7 percent. Its weak spot is still false positives on security training material, and we say so. |

## Rebuilding the video

```bash
uvicorn locus_mock.app:app --port 8000
pip install edge-tts playwright imageio-ffmpeg
python scripts/video/make_video.py        # writes out/sieve-demo.mp4
```

If the benchmark changes, rebuild: the narration picks up the new numbers. The recorder pre-warms the demo server's response cache so playground scenes reveal on cue; the latency shown on screen is from the original, uncached run.
